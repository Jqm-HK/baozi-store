# Baozi Store

API REST desenvolvida em Java e Spring Boot para gerenciamento de clientes, produtos e pedidos de uma loja fictícia de baozi.

## Tecnologias utilizadas
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Funcionalidades
- Cadastro, consulta, atualização e exclusão de clientes.
- Cadastro, consulta, atualização e exclusão de produtos.
- Cadastro, consulta, atualização e exclusão de pedidos.

## Banco de dados
O projeto utiliza MySQL para armazenar os dados da aplicação.
